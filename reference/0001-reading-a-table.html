Reading a table.

Choose columns with SELECT. Name their table with FROM.

The pattern

SELECT ID, CODE, NAME
FROM CODE_ATTRIBUTE
ORDER BY ID
FETCH FIRST 3 ROWS ONLY;
What each part does
PartMeaning
SELECTColumns to display, separated by commas.
FROMSource table.
ORDER BY IDSort by ID, smallest first.
FETCH FIRST 3 ROWS ONLYAt most three result rows.

Without ORDER BY, result order is not guaranteed. For this simple query, ID may remain in ORDER BY even when it is absent from SELECT. Oracle: Selecting Table Data; SELECT reference.

Your first SQL words

Table
Named collection of data arranged in rows and columns.
Row / record
One record, read across the grid.
Column
A named piece of information, read down the grid.
SQL
Structured Query Language: the language used here to request data.
Query
A request for data, written here as a SELECT statement.
Result set
The rows and columns returned by a query.

Sources: Oracle: Tables, Columns, and Rows; About Queries.
