Lesson 01 · About 5 minutes

Ask for a few columns.

Your first step toward joins: read one table and choose what appears in the answer.

One goal today: write a SELECT query with the columns you want.

The ideaThe queryTry itYour turn

01A table is a grid of records.

A row is one record. A column is a named piece of information, such as CODE. SQL is the language we use to ask the database for data; that request is a query. [1] [2]

02Choose columns. Name the table.

SELECT ID, CODE, NAME
FROM CODE_ATTRIBUTE
ORDER BY ID
FETCH FIRST 3 ROWS ONLY;
SELECT ID, CODE, NAME
Display these three columns, in this order.
FROM CODE_ATTRIBUTE
Read them from this table.
ORDER BY ID
Sort the answer by ID, smallest first.
FETCH FIRST 3 ROWS ONLY
Return at most three rows.

Commas separate column names. The semicolon ends the statement in your worksheet. Keep the last two lines as given while practicing SELECT and FROM. [2] [3]

The answer is called a result set. This query reads data; choosing fewer columns does not delete anything from the stored table.

04Write one yourself.

Open the starter SQL file in VS Code and use your Oracle connection’s worksheet to run its query.

Then change it to show only NAME, keeping the same ordering and three-row limit. Type the change yourself. Predict the number of result columns before running it.

Send your query and prediction to the agent. We’ll check them together before adding anything new. Ask about any word or line that feels unclear.
