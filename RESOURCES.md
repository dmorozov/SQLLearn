# Oracle SQL Resources

## Knowledge

- [Oracle 19c: Selecting Table Data](https://docs.oracle.com/en/database/oracle/oracle-database/19/tdddg/selecting-table-data.html)
  Primary beginner reading. Use the short “About Queries” section first; later
  return for specific columns, filtering, ordering, and combining tables.
  Its examples use HR, so adapt them to the verified local schema.
- [Oracle 19c: Tables and Table Clusters](https://docs.oracle.com/en/database/oracle/oracle-database/19/cncpt/tables-and-table-clusters.html)
  Use only “Overview of Tables,” “Columns,” and “Rows” for the initial vocabulary.
  Physical storage details are unnecessary for the opening lessons.
- [Oracle 19c SQL Language Reference: SELECT](https://docs.oracle.com/en/database/oracle/oracle-database/19/sqlrf/SELECT.html)
  Teacher's syntax reference. Use for SELECT lists, ORDER BY, and FETCH FIRST;
  consult individual sections rather than assign the entire page to a beginner.
- [Oracle 19c SQL Language Reference: Joins](https://docs.oracle.com/en/database/oracle/oracle-database/19/sqlrf/Joins.html)
  Ground later lessons on matching rows, outer joins, self joins, Cartesian
  products, and existence checks. Teach explicit JOIN ... ON syntax first.
