# Mission: SQL from first query to multi-table joins

## Why
Write SQL queries independently against the local Oracle database, starting with
zero SQL knowledge. The user's stated destination is to create join queries
across multiple tables; the specific work use case is still being clarified.

## Success looks like
- Read a table and choose the columns and rows needed to answer a question.
- Identify how tables relate and explain what one result row represents.
- Choose and write inner, left, right, full, cross, and self joins, including
  queries involving three or more tables.
- Handle missing matches, repeated matches, and conditions involving multiple
  columns; use existence checks when only the presence of a match matters.
- Check a query's results and explain why its rows and counts make sense.

## Constraints
- Complete beginner: introduce terminology before relying on it.
- Oracle Database 19c, accessed through Oracle SQL Developer for VS Code and MCP.
- Short lessons with practice on the existing local database.
- Advance based on demonstrated understanding, not merely covered material.

## Out of scope
- No explicit exclusions stated. Prioritize reading data and joins for now.
